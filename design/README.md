# INQABA DESIGN STUDIO

This directory is an isolated UI/UX design and prototyping workspace.

## Architectural Rule
- All prototypes use local mock data (`~/inqaba/design/mock-data/`).
- No live connections to PostgreSQL, PostGIS, n8n, or Docker services are permitted in this phase.
- The core engineering files in the repository root remain frozen.

## Environment Index
1. `prototypes/public-web`: Institutional public portal.
2. `prototypes/atlas`: ATLAS operational and spatial project portal.
3. `prototypes/executive`: Executive decision-support dashboards.
4. `prototypes/forensics`: High-density dark analytical and investigation workspace.
5. `prototypes/field-mobile`: High-contrast, mobile-first field inspection interface.
